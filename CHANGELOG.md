# 📒 Changelog

## [0.1.0] - 2026-11-09

### ✨ Added
- Fit library: power law, exponential, logarithmic, sigmoid, linear.
- BIC model selection (fit quality minus complexity).
- EXTRAPOLATION GATE: fit on the first half, predict the unseen second half.
- Equation cards with honest verdicts: equation | curve-fit-only | no-fit.
- Built-in curve library including a changepoint honesty check that must fail the gate.
- User curves via JSON input; bounded CI tests; production infra.
